# Amaanah

> **The Halal Financial Companion** — Helping Muslims understand their finances, calculate Zakat confidently, build financial literacy, and access vetted halal investment opportunities.

## Project Structure

- `PRD.md` — Product Requirements & Direction document
- `amaanah-mobile/` — React Native / Expo mobile application
- `amaanah-server/` — Backend services and APIs

## Getting Started

### Mobile Application

```bash
cd amaanah-mobile
npm install
npx expo start
```
